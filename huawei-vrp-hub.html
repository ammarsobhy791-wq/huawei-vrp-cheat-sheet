High Availability — Redundancy
VRRP + Eth-Trunk للبيئات الحرجة
🔄 VRRP — Gateway Redundancy
# Core Switch 1 — Master interface Vlanif10 ip address 192.168.10.2 255.255.255.0 vrrp vrid 1 virtual-ip 192.168.10.1 # Virtual GW للـ Clients vrrp vrid 1 priority 120 # أعلى priority = Master vrrp vrid 1 preempt-mode timer delay 5 # Core Switch 2 — Backup interface Vlanif10 ip address 192.168.10.3 255.255.255.0 vrrp vrid 1 virtual-ip 192.168.10.1 # نفس الـ Virtual GW vrrp vrid 1 priority 100 # Default = Backup display vrrp # عرض الحالة

Best Practices — Production Environment
من تجارب الـ Real World في البيئات الحرجة
01
Save دايماً بعد أي تغيير
الـ VRP بيحتفظ بالتغييرات في RAM فقط — لو الجهاز أعاد تشغيله ضاع كل حاجة
save
02
استخدم MSTP مش STP
MSTP أسرع في الـ Convergence وبيدعم Load Balancing عبر Instances مختلفة لكل VLAN
stp mode mstp
03
BPDU Protection على مستوى النظام
يحمي الـ Edge Ports من استقبال BPDUs من Switch غير مصرح به في الشبكة
stp bpdu-protection
04
SSH فقط — ممنوع Telnet
Telnet بيبعت الـ Password بالنص الصريح. في Production لازم SSH + AAA دايماً
undo telnet server enable
05
Backup قبل أي تغيير
احفظ الـ Current Config على TFTP Server أو انسخها قبل أي تعديل في Production
display current-configuration
06
وصف كل Interface
description على كل Port بيوفر ساعات من الـ Troubleshooting لما حاجة تتعطل
description To-Core-SW01-P1
07
VRRP للـ Gateway Redundancy
أي Core Switch يموت → الـ Clients تتحول للـ Backup تلقائياً خلال ثوانٍ بدون تدخل
vrrp vrid 1 virtual-ip x.x.x.x
08
Eth-Trunk على الـ Uplinks الحرجة
2-4 Ports مجمعة = Bandwidth أعلى + Redundancy تلقائية لو كابل اتقطع
mode lacp-static
09
NTP — وقت موحد على الشبكة
بدون NTP الـ Logs مش هتتطابق في الوقت وهيبقى Troubleshooting صعب جداً
ntp-service unicast-server x.x.x.x
10
Idle Timeout على الـ VTY
Sessions مفتوحة = ثغرة أمنية. فعّل Timeout لإغلاق الجلسات الخاملة تلقائياً
idle-timeout 10 0
11
Port Security على Access Ports
يمنع ربط Switch غير مصرح به أو تغيير الجهاز المتصل بدون علمك
port-security mac-address sticky
12
Router-ID ثابت في OSPF
بدون Router-ID ثابت لو Interface وقع هيتغير الـ ID ويسبب Adjacency Reset لكل الجيران
ospf 1 router-id 1.1.1.1
